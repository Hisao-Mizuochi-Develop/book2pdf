# 📖 BOOK2PDF_AGENT_SKILLS_MANUAL

> 最終更新: 2026/09/13
本マニュアルは、VSCodeのAIアシスタント（Cline / Roo Code）をはじめ、CursorやClaude Codeに展開された book2pdf プロジェクト専用の拡張スキル（Agent Skills）を、チャット欄から「 `/`（スラッシュ）」を使ってピンポイントで呼び出すための完全操作説明書です。

初学者からシニアエンジニアまで、開発チーム全員が共通のルールでAIを強力なツールとして使いこなすために作成されました。

---

## 📌 はじめに：スラッシュコマンドを使うメリット

通常の自律モード（自動実行）では、AIは `.clinerules` に定められた重厚なステップ（Gate 1/2の計画承認や前提確認）を踏むため、起動までに時間がかかります。
しかし、チャット欄の冒頭に `/コマンド名` を入力すると、AIは面倒な手続きをすべてスキップし、**「その仕事だけ」をその場ですぐに実行（瞬時解決）** してくれます。

    5. ` /status 現在のブランチがPhase 3（実装・検証）の条件を満たしているか教えて`
    6. ` /workflow Gate 1を通過したあとの計画書のステータスを表示して`
    7. ` /status 最終報告（Phase 4）に進むための残りのステップを教えて`

## 💡 知っておくと便利な「AIが守る裏ルール」
ユーザーが `/` コマンドでピンポイントの指示を出したとき、AIは以下のプロジェクト最高綱領（`.clinerules`）をバックグラウンドで厳格に守りながら動いています。

1.  **ファイルの強制上書き禁止 (`write_to_file`の制限)**
    すでに存在するファイルを書き換えるときは、必ず部分的な「差分置換（`replace_in_file`）」を使い、ファイルを丸ごと破壊するのを防ぎます。
2.  **AIによるブランチ削除の絶対禁止**
    マージやプッシュが終わっても、AIは自分でブランチを削除しません。必ず「人間開発者が手動で実行するためのコマンド」をテキストで提示し、最終判断をあなたに委ねます。
3.  **言語別スタイル・コメントの自動付与**
    コードを生成するときは、指定されたスタイルガイド（Python, Rust, TypeScript）に沿って、関数への説明（docstring等）や、`import` / `use` 文への役割解説コメントを自動で丁寧に入力します。
4.  **CPU実行制約の死守**
    `ocr-worker/` などの環境でライブラリを導入またはコード生成する際、GPUやCUDAへの依存を一切排除し、CPU環境のみで100%安全に動くロジックを構成します。
5.  **セキュリティ監査によるマージ/コミット強制ブロック**
    `/audit` によって秘密情報のハードコードや脆弱性が検知された場合、AIはプロセスを自動で中断し、安全が確保されるまでコミットやマージの手続きを拒否します。
