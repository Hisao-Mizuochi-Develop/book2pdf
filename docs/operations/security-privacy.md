# セキュリティ・プライバシーノート

## 通信・データ送信について

kindle2pdf は**外部ネットワーク通信を行いません**。すべての処理（画面キャプチャ・
画像トリミング・OCR・PDF/Markdown生成）はローカルマシン上で完結します。

- OCRエンジン（NDLOCR-Lite）はクラウドAPIではなく、ローカルにインストールした
  ONNXモデルをCPU（onnxruntime）で実行します
- 段落整形（`text_reflow.py`）はルールベースの処理で、LLMや外部APIを使いません
- キャプチャした画像・OCR結果・生成したPDF/Markdownは、ユーザーが指定した
  ローカルフォルダにのみ保存されます

唯一の例外は、初回セットアップ時に `git clone` で NDLOCR-Lite を
GitHubから取得する操作（`https://github.com/ndl-lab/ndlocr-lite.git`）です。
これはインストール時の1回のみで、アプリの通常動作には影響しません。

## macOSのプライバシー権限が必要な理由

kindle2pdf は以下の2つの権限を要求します。詳細は
[../user/permissions.md](../user/permissions.md) を参照してください。

| 権限 | 用途 | 範囲 |
|------|------|------|
| 画面収録 | 対象アプリのウィンドウ検出・スクリーンショット取得 | 画面上に表示されている内容の読み取りのみ。外部送信なし |
| アクセシビリティ | ページめくりキー・クリックの合成入力送信 | 対象アプリへのキー/クリック送信のみ。他の監視機能なし |

これらの権限は、電子書籍アプリの画面を自動操作・撮影するという
アプリの性質上必須のものであり、それ以外の目的（テレメトリ収集等）には
一切使用していません。

## キャプチャ対象について

- 自動キャプチャは、ユーザーが選択した特定のウィンドウ（プロファイルで
  指定したアプリ）のみを対象とします。画面全体の常時録画は行いません
- キャプチャ対象ウィンドウが最前面でなくなった場合は自動的に停止します
  （誤って別のアプリの画面を撮影し続けることを防ぐ設計）

## 著作権について利用上の注意

本ツールは個人の学習目的での利用を想定しています。電子書籍のスクリーン
キャプチャ・複製は、購入した電子書籍の利用規約や著作権法の範囲内で
行ってください。生成したPDF/Markdownファイルの第三者への配布・共有は
著作権侵害となる可能性があるため、個人利用の範囲に留めてください。

## 依存パッケージについて

外部の未検証パッケージの混入を避けるため、`requirements.txt` は
バージョンを固定（pin）しています。依存関係を変更する場合は
`pyproject.toml` を編集した上で `uv pip compile` で再生成してください
（詳細は `pyproject.toml` 冒頭のコメントを参照）。
