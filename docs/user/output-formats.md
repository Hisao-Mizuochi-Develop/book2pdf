# 出力形式の選び方

変換タブで選べる5つの出力形式の比較と、用途別のおすすめです。

## 比較表

| 形式 | OCR | ファイルサイズ | 検索性 | 見た目 | 主な用途 |
|------|-----|--------------|--------|--------|---------|
| 画像PDF | 不要 | 大〜中 | なし | 元画像そのまま | タブレット閲覧、印刷、最速で欲しいとき |
| テキストPDF | 必要 | 小 | ◎（本物のテキスト） | OCR結果のテキストのみ | GoodNotesへの取り込み、注釈用の軽量版 |
| 検索可能PDF | 必要 | 大（画像＋テキスト） | ◎（不可視レイヤー） | 画像PDFと同一 | 見た目を保ちつつ検索したい |
| Markdown | 必要 | 極小 | テキストエディタ次第 | プレーンテキスト | 二次利用、ブログ執筆、LLMへの読み込み |
| 画像+テキストPDF | 必要 | 大（画像＋テキスト） | ◎（本物のテキスト） | 画像ページ→テキストページの繰り返し | OCR結果の校正、原文と抽出結果の見比べ |

## 選び方フローチャート（テキスト版）

1. **OCRは使いたくない / とにかく早く欲しい** → 画像PDF
2. **iPadなどでテキスト注釈をつけたい** → テキストPDF または 画像PDF
3. **見た目は画像のままで検索もしたい** → 検索可能PDF
4. **テキストデータだけ欲しい（LLM入力・ブログ原稿など）** → Markdown
5. **OCRの精度を見比べたい / 画像と本文を両方保存したい** → 画像+テキストPDF

## 各形式の内部処理（実装）

- 画像PDF: `core/pdf_builder.py` の `images_to_pdf()`。画像を等倍でPDFページ化するだけ
- テキストPDF: `text_to_pdf()`。OCR結果をreportlabの `Paragraph` で流し込み、自動改ページ
- 検索可能PDF: `images_to_searchable_pdf()`。画像を描画した上に `setTextRenderMode(3)`（不可視）でテキストを重ねる
- Markdown: `core/markdown_writer.py` の `write_markdown()`。ページごとに `<!-- page: ファイル名 -->` 区切り
- 画像+テキストPDF: `images_with_text_pdf()`。1ページごとに「画像1ページ + テキスト1ページ以上（自動改ページ）」を繰り返す

いずれも `chapters`（章自動検出結果）を渡すとPDFしおり／Markdown見出しが挿入されます。
