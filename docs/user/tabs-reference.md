# タブ別機能リファレンス

book2pdf は4つのタブで構成されています。各タブの設定項目と挙動をまとめます。

## キャプチャタブ

電子書籍アプリのページを自動で連続スクリーンショットします。

| 項目 | 説明 |
|------|------|
| プロファイル選択 | 対象アプリのプリセット（`kindle` / `google_play` の2種が既定。カスタム追加可） |
| ページめくり方向 | 右めくり（通常書籍） / 左めくり（漫画・縦書き） |
| 待機時間(秒) | ページめくり後、次の撮影までの待機。短いほど速いが描画待ちに失敗しやすい |
| タイトル / フォルダ | 保存先。`フォルダ/タイトル/001.png, 002.png, ...` の連番で保存 |
| 詳細設定 | ウィンドウタイトルキーワード、プロセス名、境界検出方式などプロファイルの中身を編集 |
| 領域プレビュー | 現在の画面から検出したキャプチャ範囲を緑線で表示 |
| 手動領域選択 | ドラッグでキャプチャ範囲を手動指定（`boundary_method: manual`） |

内部動作の詳細は [../developer/architecture.md](../developer/architecture.md) と
[../diagrams/capture-sequence.md](../diagrams/capture-sequence.md) を参照してください。

ページめくりは「右矢印キー」を基本としつつ、反応がない場合は自動的に
スペース → PageDown → 下矢印 → スクロールへとフォールバックします
（詳細は [troubleshooting.md](troubleshooting.md)）。

## PDF読込タブ

既存PDFを画像フォルダに展開します。「キャプチャ」の代替入力源です。

| 項目 | 説明 |
|------|------|
| PDFファイル | 変換元のPDF |
| 出力フォルダ | 未設定時は `<PDF名>_pages` を自動設定 |
| DPI | 150〜400。OCR目的なら200〜300、印刷向けなら300〜400 |
| 形式 | PNG（無劣化）/ JPG（軽量） |

## トリミングタブ

キャプチャ・PDF展開した画像の余白を一括カットします。

| 項目 | 説明 |
|------|------|
| 入力/出力フォルダ | 前段タブから自動引き継ぎ。出力は入力と別フォルダにすること |
| 余白（左右上下） | カットするピクセル数 |
| 自動検出 | 先頭・中央・末尾付近の数枚をサンプリングし、4辺の余白を推定（やや余裕を持たせた値） |
| デフォルトとして保存 | 次回起動時に自動適用される既定値として `config.json` に保存 |
| プレビュー | before/afterを並べて表示。「◀ 前へ」「次へ ▶」でページ送り |

## 変換タブ

トリミング済み（またはキャプチャ直後の）画像を各種形式に変換します。

| 出力形式 | OCR | 説明 |
|---------|-----|------|
| 画像PDF | 不要 | 画像をそのまま1つのPDFに結合 |
| テキストPDF | 必要 | OCR抽出テキストのみの軽量PDF |
| 検索可能PDF | 必要 | 画像 + 不可視OCRテキスト（見た目は画像のままCtrl+F検索可能） |
| Markdown | 必要 | OCRテキストを `.md` として出力。「ページ画像を併記」で画像リンクも埋め込み可 |
| 画像+テキストPDF | 必要 | 画像ページ→同じページのOCRテキストページ、を全ページ繰り返す見開き型PDF |

形式ごとの使い分けは [output-formats.md](output-formats.md) を参照してください。

共通オプション（OCRを使う形式で有効）:

- **OCR前処理**: Lanczosアップスケール・コントラスト強調（電子書籍のアンチエイリアス文字に有効）
- **置換辞書 (replacements.json)**: OCR誤認識の機械的な置換ルール
- **章しおり自動検出**: 「第◯章」等のパターンを検出しPDFしおり/Markdown見出しに変換
- **段落を自動整形**: OCRの改行ノイズを段落として結合（Markdown・画像+テキストPDFで使用可）
