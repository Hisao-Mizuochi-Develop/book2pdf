# クイックスタート

セットアップが済んでいる前提で、Kindleの本を1冊まるごとPDF化するまでの
最短手順を説明します。（未セットアップの場合は [setup.md](setup.md) を先に）

## 全体の流れ

```
[1a. キャプチャ]  ┐
                  ├→ 2. トリミング → 3. 変換（PDF / Markdown）
[1b. PDF読込  ]  ┘
```

入力源は「キャプチャ」（電子書籍アプリを自動で撮影）と「PDF読込」（既存PDFを画像化）の
どちらかから選べます。出力フォルダは次のタブへ自動で引き継がれます。

## ステップ1: キャプチャ

1. Kindle（またはお使いの電子書籍アプリ）で本を開き、**最初のページ**を表示する
2. book2pdf を起動し、「キャプチャ」タブを開く
3. 「プロファイル選択」で `kindle` を選ぶ
4. 「保存設定」の「入力」でタイトルを入力（空欄なら日時が使われる）
5. 「参照」で保存先フォルダを選ぶ
6. 「キャプチャ開始」を押す

初回はmacOSから「画面収録」「アクセシビリティ」の許可を求められます。
必ず許可してください（[permissions.md](permissions.md) 参照）。

キャプチャ中はマウス・キーボードに触れないでください。最後のページに
到達すると自動で停止します。

## ステップ2: トリミング（任意）

キャプチャ直後は入力フォルダが自動設定されています。

1. 「余白」欄で上下左右にカットするピクセル数を指定（「自動検出」ボタンでも概算できます）
2. 「プレビュー」で仕上がりを確認
3. 問題なければ「トリミング実行」

余白がなければこのタブはスキップして構いません。

## ステップ3: 変換

1. 画像フォルダが自動設定されている（キャプチャ or トリミング後）
2. 出力形式を選ぶ（詳しくは [output-formats.md](output-formats.md)）
   - まず試すなら **画像PDF**（OCR不要・最速）
3. OCRを使う形式の場合、OCRエンジン欄に「NDLOCR-Lite」が表示されているか確認
4. 出力先フォルダとファイル名を指定
5. 「変換実行」

完了すると出力先にファイルが生成されます。

## 「PDF読込」タブを使う場合

すでに手元にPDF（自炊スキャン・購入済みPDFなど）がある場合は、キャプチャの
代わりに「PDF読込」タブを使います。

1. 「参照」でPDFファイルを選ぶ
2. 出力フォルダ（未設定なら `<PDF名>_pages` が自動設定）
3. DPI（OCR目的なら200〜300）と形式（PNG/JPG）を選ぶ
4. 「画像に展開」

以降はキャプチャと同様に、トリミング → 変換に進めます。
