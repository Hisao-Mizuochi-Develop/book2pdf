# 03-capture.md — 自動キャプチャエンジン

## ゴール

電子書籍アプリの表示ページを自動でめくりながら連続スクリーンショットし、連番 PNG ファイルとして保存する。

## ファイル構成

```
core/
├── capture_profiles.py    # CaptureProfile クラス、ビルトイン/カスタムプロファイル
├── boundary_detector.py   # キャプチャ範囲検出（full / manual / auto）
└── capture_engine.py      # 自動キャプチャループ
```

## CaptureProfile

```python
@dataclass
class CaptureProfile:
    name: str
    window_title_keyword: str
    page_turn_key: str = "right"
    fullscreen_wait: float = 5.0
    page_wait: float = 0.5
    boundary_method: str = "full"  # "full" | "manual" | "auto"
    manual_left: int = 0
    manual_right: int = 0
    process_name: str = ""
    timeout_seconds: float = 5.0
    max_retries: int = 3
```

## ビルトインプロファイル

最低限以下を提供する。

| キー | 名称 | ウィンドウタイトルキーワード |
|------|------|---------------------------|
| `kindle` | 電子書籍 | `kindle` |
| `google_play` | Google Play ブックス | `Google Play ブックス` |

カスタムプロファイルは `config.json` の `capture.profiles` に保存できる。

## 境界検出

`core/boundary_detector.py` で以下を実装する。

- `FullFrameBoundary`: クロップなし
- `ManualBoundary`: 手動指定した left/right に従う
- `AutoBoundary`: コンテンツ領域を検出（詳細は `05-trim.md` と共用してもよい）

## キャプチャアルゴリズム

`CaptureEngine` クラスで実装する。

1. 対象ウィンドウを検索・前面化する
2. 画面収録・入力自動化権限を確認する。無ければ開始せずエラーを表示
3. 境界検出方式に応じてクロップ範囲を決定する
4. ループ:
   1. 対象ウィンドウが最前面か確認する。最前面でなければ安全に停止
   2. `page_wait` 秒待ってスクリーンショットを取得
   3. 直前の保存画像と比較し、差分ピクセル比率が閾値（目安 0.5%）を超えた場合のみ「変化した」とみなす
   4. 変化を検出したら連番ファイル名で保存し、ページめくり操作を送信する
   5. `timeout_seconds` 経過しても変化がなければ、ページめくり方式を自動エスカレーションする
   6. 全方式を試しても変化がなければ「最終ページに到達」とみなして停止する
5. 完了時に合計ページ数と保存先を通知し、`AppState` で `capture_complete` イベントを発行する

## ページめくりエスカレーション

既定キーが効かない場合、以下の順に自動で試行する。一度有効な方式が見つかったら、以降のページもその方式を使い続ける。

1. プロファイル指定のキー（例: `right`）
2. `space`
3. `pagedown`
4. `down`
5. マウスホイールスクロール

## ページめくり方向

- 右めくり（通常書籍）: 上記の順
- 左めくり（漫画・縦書き）: 逆向きのキー（`left` / `pageup` / `up`）を試行

## 停止処理

- 「停止」ボタンで安全に中断できる
- スレッド内で停止フラグをポーリングし、キャプチャ保存直後にループを抜ける
- 中断時も、既に保存済みの画像は破棄しない

## UI 要件（capture_tab.py）

- プロファイル選択ドロップダウン
- ページめくり方向（右めくり / 左めくり）
- 待機時間（秒）入力
- タイトル入力（空欄時は現在日時）
- 保存先フォルダ選択
- キャプチャ開始/停止ボタン
- 進捗ログ表示
- 詳細設定折りたたみパネル（プロファイル項目の直接編集）
- 領域プレビューボタン（現在画面のキャプチャ範囲を緑線でオーバーレイ表示）
- 手動領域選択ボタン（マウスドラッグで境界を指定）
- プロファイル保存ボタン（複製して保存 / 上書き保存）

## 完了条件

- 電子書籍アプリで 6 ページ程度の連続自動キャプチャが成功する
- 生成された画像が実際に異なるページ内容であることを目視確認する
- 同一ページ内容の画像が連番で量産されていないことを確認する
- 最前面から外した際に安全に停止すること
- 権限が無い場合は明確なエラーメッセージを表示すること
