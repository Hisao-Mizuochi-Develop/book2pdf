# 09-trim.md — トリミング・余白検出

## ゴール

キャプチャまたは PDF 展開で得た画像の余白を一括カットする。

## ファイル構成

```
core/
├── boundary_detector.py   # コンテンツ領域検出（キャプチャと共用）
└── trimmer.py             # トリミング実行
```

## 機能要件

### UI 項目

| 項目 | 説明 |
|------|------|
| 入力フォルダ | 前段タブから自動引き継ぎ |
| 出力フォルダ | 入力と別フォルダを強制または警告 |
| 余白（左右上下 px） | 個別入力 |
| 自動検出 | 先頭・中央・末尾付近をサンプリングし、4 辺の余白を推定 |
| デフォルトとして保存 | 次回起動時に自動適用される既定値として保存 |
| プレビュー | before/after を並べて表示。ページ送りナビゲーション付き |

### 自動検出ロジック

1. 入力フォルダから先頭・中央・末尾付近の数枚をサンプリングする
2. 各画像で 4 隅の色を背景とみなし、コンテンツ領域を検出する
3. サンプル間で最大のコンテンツ領域を採用する
4. **検出値そのままではなく、やや余裕を持たせた値（安全マージンを引いた値）を初期値として提示する**
5. ユーザーが手動で寄せていく運用を想定
