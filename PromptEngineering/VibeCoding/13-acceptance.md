# 13-acceptance.md — 完成判定チェックリスト

## 目的

コードレビューだけでは保証できない GUI 自動操作・画像処理・OCR の動作を、実機で確認する。

## 前提確認

- [ ] `python --version` が 3.11〜3.13 の範囲内
- [ ] `python -c "import tkinter"` がエラーなく通る
- [ ] （macOS のみ）`pyobjc-framework-Quartz` 等がインストール済み
- [ ] `ruff check .` と `pytest` がパスしている

## core/platform/ 疎通確認

以下のワンショットスクリプトで確認する。

```python
from core.platform import find_window, get_window_rect, activate_window, is_window_frontmost

hwnd = find_window("kindle", process_name="Kindle.exe")  # Windows
# hwnd = find_window("kindle", process_name="Kindle")    # macOS
assert hwnd is not None
rect = get_window_rect(hwnd)
print("rect:", rect)
activate_window(hwnd)
assert is_window_frontmost(hwnd)
```

- [ ] 対象アプリが起動していない状態で `find_window(..., process_name=...)` が `None` を返す
- [ ] 対象アプリを起動した状態で `find_window()` が正しいウィンドウを検出する
- [ ] `activate_window()` 実行後、ウィンドウ状態が変化していない
- [ ] `get_window_rect()` の座標をそのままスクリーンショットの bbox に渡すと対象ウィンドウが写る

## キャプチャ機能の実機確認

- [ ] 電子書籍アプリで本を開き、1 ページ目が正しく保存される
- [ ] 2 ページ目以降の画像が**内容の異なる**連番ファイルとして保存される
- [ ] 同一ページ内容の画像が連番で量産されていない
- [ ] 最後のページに到達すると自動停止し、正しい合計ページ数が報告される
- [ ] 「停止」ボタンで安全に中断できる
- [ ] キャプチャ中に対象ウィンドウを最前面から外すと安全に停止しエラーメッセージが表示される
- [ ] 権限が無い状態で実行すると、明確なエラーメッセージが表示される

### ページめくりエスカレーション

- [ ] 無効なページめくりキーを設定しても、一定時間後に別方式にエスカレーションする
- [ ] エスカレーション後、複数ページ連続して正しく撮影が進行する
- [ ] ログ/ステータスに「別の方式を試します」等の案内が出る

## PDF 読込タブ

- [ ] PDF ファイルを選択すると出力フォルダが `<PDF名>_pages` に自動設定される
- [ ] DPI を変えて展開すると、画像サイズが期待通りスケールする
- [ ] 展開後、トリミング/変換タブに出力フォルダが自動引き継がれる

## トリミングタブ

- [ ] 自動検出で 4 辺の余白が概算され、安全マージンを持たせた値になっている
- [ ] プレビューの before/after が実際のトリミング結果と一致する
- [ ] トリミング実行で全画像が一括処理される
- [ ] デフォルトとして保存した値がアプリ再起動後も引き継がれる

## 変換タブ — 5 形式すべて

- [ ] **画像 PDF**: OCR なしで生成され、全ページが正しい順序で含まれる
- [ ] **テキスト PDF**: OCR が実行され、長文時に自動改ページされる
- [ ] **検索可能 PDF**: 見た目は画像 PDF と同一だが、テキスト検索できる
- [ ] **Markdown**: `.md` ファイルが生成され、ページ区切りとフロントマターが含まれる
- [ ] **画像＋テキスト PDF**: ページ順が「画像→テキスト→画像→テキスト...」で正しく繰り返されている

### 共通オプション

- [ ] OCR 前処理の有無で OCR 結果の精度に差が出る
- [ ] 置換辞書ルールが OCR 結果に反映される
- [ ] 章自動検出が有効な場合、PDF しおり/Markdown 見出しに反映される
- [ ] 段落自動整形で OCR の改行ノイズが結合される

## 設定の永続化

- [ ] アプリ再起動後、前回保存した設定が復元される

- [ ] 未知のキーを含む `config.json` を読み込んでもエラーにならない
