# book2pdf VibeCoding プロンプト群

このディレクトリには、熟練したソフトウェアエンジニアの AI コーディングアシスタントに book2pdf を **0 から VibeCoding させるためのプロンプト**が含まれています。

## 使い方（新規開発手順）

1. **前提知識の読み込み**
   熟練したソフトウェアエンジニアの AI コーディングアシスタント に以下のファイルを順に読み込ませてください。

   1. `00-design.md` — アーキテクチャ・技術選定・設計原則
   2. `11-pitfalls.md` — 過去の実装で発生した不具合と回避策
   3. `12-testing.md` — テスト戦略と観点
   4. `13-distribution.md` — 配布ビルド方針

2. **実装フェーズ**
   `01-setup.md` から `08-gui.md` まで順に実装を進めさせてください。
   各フェーズ終了時は、必ず `12-testing.md` の該当単体テストと `09-acceptance.md` の該当項目を実施させてください。

3. **最終確認**
   全フェーズ完了後、`09-acceptance.md` の全項目を実機で確認し、`13-distribution.md` に従って配布ビルドを作成してください。

## ファイル一覧

| ファイル | 内容 |
|---------|------|
| `00-design.md` | アーキテクチャ、技術選定、設計原則 |
| `01-setup.md` | 環境構築、依存導入、run.sh/run.bat |
| `02-platform.md` | Windows/macOS プラットフォーム抽象化層 |
| `03-capture.md` | 自動キャプチャエンジン、プロファイル |
| `04-pdf-load.md` | PDF → 画像展開 |
| `05-trim.md` | 余白検出、トリミング |
| `06-ocr.md` | OCR 抽象化、NDLOCR-Lite 連携、前後処理 |
| `07-convert.md` | 5 出力形式の PDF/Markdown 生成 |
| `08-gui.md` | タブベース GUI（熟練したソフトウェアエンジニアの AI コーディングアシスタント がデザイン提案） |
| `09-acceptance.md` | 実機受け入れチェックリスト |
| `10-run.md` | 開発進行プロンプト（マスター指示） |
| `11-pitfalls.md` | 既知の落とし穴と回避策 |
| `12-testing.md` | テスト戦略・観点 |
| `13-distribution.md` | PyInstaller ローカルビルド手順 |

## 補足

- GUI のタブ内部デザインは `08-gui.md` の指示に従い、熟練したソフトウェアエンジニアの AI コーディングアシスタント が複数案を提案しユーザー確認を得てから実装します。
- OCR エンジンの追加・変更については `docs/operations/ocr-engines.md` を参照・更新してください。
- 配布ビルドは macOS の `.app` と Windows の `.exe` に対応しますが、ビルド自体は各 OS 上で行う必要があります。
