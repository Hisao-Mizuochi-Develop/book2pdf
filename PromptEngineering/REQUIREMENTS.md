# REQUIREMENTS.md — 機能要件仕様

kindle2pdf が満たすべき全機能要件です。`PROMPT.md` から参照される一次情報源。

## アプリ概要

電子書籍のスクリーンキャプチャ・PDF読込・トリミング・PDF変換・OCRを
1つのGUIアプリ（4タブ構成）で行う、個人学習用ツール。

```
[1a. キャプチャ]  ┐
                  ├→ 2. トリミング → 3. 変換（PDF / Markdown）
[1b. PDF読込  ]  ┘
```

- 入力源は「キャプチャ」または「PDF読込」のどちらかから選べる
- 出力フォルダは次のステップへ自動で引き継がれる
- 各タブは独立して動作する（例: 既にトリミング済みの画像を直接「変換」タブに渡してもよい）

## タブ1: キャプチャ

電子書籍アプリの表示ページを自動でめくりながら連続スクリーンショットする。

### UI要素

| 項目 | 型 | 説明 |
|------|-----|------|
| プロファイル選択 | ドロップダウン | ビルトイン+カスタムプロファイルから選択 |
| ページめくり方向 | ラジオボタン | 右めくり(通常) / 左めくり(漫画・縦書き) |
| タイトル入力 | テキスト+ダイアログ | 空欄時は現在日時を使用。保存先のサブフォルダ名になる |
| 保存先フォルダ | フォルダ選択 | 選択フォルダ内に `<タイトル>/001.png, 002.png, ...` で連番保存 |
| キャプチャ開始/停止ボタン | ボタン | 開始で別スレッド起動、停止で安全に中断 |
| 進捗ログ | テキスト表示 | ページ番号・経過時間・エラーをリアルタイム表示 |
| 詳細設定（折りたたみ） | 展開パネル | 下記プロファイル項目を直接編集 |
| 領域プレビュー | ボタン | 現在画面のキャプチャ範囲を緑線でオーバーレイ表示 |
| 手動領域選択 | ボタン+ドラッグUI | マウスドラッグで境界を手動指定 |
| プロファイル保存 | ボタン | 「複製して保存」(新規名) / 「上書き保存」(既存プロファイル更新) |

### プロファイル項目（CaptureProfile）

| フィールド | 型 | 既定値 | 説明 |
|-----------|-----|--------|------|
| `name` | str | - | 表示名 |
| `window_title_keyword` | str | - | ウィンドウタイトルの検索キーワード（大文字小文字無視・部分一致） |
| `page_turn_key` | str | `"right"` | ページめくりキー |
| `fullscreen_wait` | float | `5.0` | ウィンドウ前面化後、キャプチャ開始までの待機秒数 |
| `page_wait` | float | `0.5` | ページめくり後、次の撮影確認までの待機秒数 |
| `boundary_method` | str | `"full"` | `"full"`(クロップなし) / `"manual"`(手動範囲) |
| `manual_left` / `manual_right` | int | `0` | 手動境界時のウィンドウ相対クロップ座標 |
| `process_name` | str | `""` | プロセス名フィルタ。空なら無効 |
| `timeout_seconds` | float | `5.0` | 1ページあたり無変化とみなすタイムアウト |
| `max_retries` | int | `3` | 例外・保存失敗時のリトライ上限 |

### ビルトインプロファイル（最低限）

| キー | アプリ | ウィンドウタイトルキーワード |
|------|--------|---------------------------|
| `kindle` | Kindle (Windows: Kindle for PC / macOS: Amazon Kindle) | `kindle` |
| `google_play` | Google Play ブックス | `Google Play ブックス` |

### キャプチャアルゴリズム（必須要件）

1. 対象ウィンドウを検索・前面化する（`CROSS_PLATFORM.md` の抽象化を使う）
2. **画面収録・キー入力送信に必要な権限を確認する**（OS依存。macOSでは
   画面収録・アクセシビリティ権限。詳細は `CROSS_PLATFORM.md`）。権限が
   無ければキャプチャを開始せず、明確なエラーメッセージを表示する
3. 境界検出方式に応じてクロップ範囲(left, right)を決定する
4. ループ:
   a. 対象ウィンドウが最前面か確認する。最前面でなければ安全に停止し
      エラー表示する（誤って別ウィンドウ/デスクトップを撮り続けない）
   b. `page_wait` 秒待ってスクリーンショットを取得し、直前の保存画像と比較する
   c. **「実質的な変化」の判定は、1ピクセルでも異なれば変化とみなす方式を
      禁止する。** ノイズ（カーソル点滅、時計表示等）による誤検出を防ぐため、
      差分ピクセル比が一定閾値（目安0.5%）を超えた場合のみ「変化した」と
      みなすこと
   d. 変化を検出したら連番ファイル名で保存し、ページめくり操作を送信する
   e. `timeout_seconds` 経過しても変化がなければ、**ページめくり方式を
      自動でエスカレーションする**（例: 矢印キー→スペース→PageDown→
      下矢印→マウスホイールスクロール）。一度有効な方式が見つかったら、
      以降のページもその方式を使い続ける
   f. 全方式を試しても変化がなければ「最終ページに到達」とみなして停止する
5. 完了時に合計ページ数と保存先を通知し、次タブへ自動引き継ぎする

## タブ2: PDF読込

既存PDF（自炊スキャン・購入済みPDF等）を画像フォルダに展開する。
キャプチャタブと並ぶ、もう一つの入力源。

| 項目 | 説明 |
|------|------|
| PDFファイル選択 | ファイルダイアログ |
| 出力フォルダ | 未設定なら `<PDF名>_pages` を自動設定 |
| DPI | 150/200/300/400 から選択。OCR目的なら200〜300 |
| 形式 | PNG(無劣化) / JPG(軽量) |

展開後、`001.png, 002.png, ...` の連番で保存し、トリミング・変換タブへ
自動引き継ぎする。

## タブ3: トリミング

画像の余白を一括カットする。

| 項目 | 説明 |
|------|------|
| 入力/出力フォルダ | 前段タブから自動引き継ぎ。入力≠出力を強制または警告する |
| 余白（左右上下、px） | 個別入力 |
| 自動検出 | 先頭・中央・末尾付近を複数サンプリングし、4隅の色を背景とみなして
コンテンツ領域を検出。**検出値そのままではなく、やや余裕を持たせた値
（安全マージンを引いた値）を初期値として提示すること**（ユーザーが
手動で寄せていく運用を想定） |
| デフォルト保存 | 次回起動時に自動適用される既定値として設定に保存 |
| プレビュー | before/afterを並べて表示。ページ送りナビゲーション付き |

## タブ4: 変換

トリミング済み（またはキャプチャ直後の）画像を以下5形式に変換する。

| 形式 | OCR | 説明 |
|------|-----|------|
| 画像PDF | 不要 | 画像をファイル名昇順でそのまま1つのPDFに結合 |
| テキストPDF | 必要 | OCR抽出テキストのみの軽量PDF（自動改ページ対応） |
| 検索可能PDF | 必要 | 画像を描画した上に不可視テキストレイヤーを重ね、外見は画像のままCtrl+F検索可能にする |
| Markdown | 必要 | OCRテキストをページ区切り付き `.md` として出力。ページ画像を本文に併記するオプションあり |
| 画像+テキストPDF | 必要 | 各ページについて「画像1ページ→同じページのOCRテキスト1ページ以上（自動改ページ）」を繰り返す見開き型PDF |

### 共通オプション（OCRを使う形式で有効化）

- **OCR前処理**: Lanczosアップスケール（1.0/1.5/2.0倍）+ コントラスト自動調整（autocontrast）。
  二値化は既定OFF（地色が薄い本・カラー図版で逆効果になりやすいため）
- **置換辞書**: ユーザー定義の `literal`（文字列置換）/ `regex`（正規表現置換）ルールを
  OCR結果に適用。辞書ファイルが存在しない/壊れている場合はno-opまたは
  明確なエラーメッセージで動作継続する（アプリを落とさない）
- **章自動検出**: 「第◯章」「Chapter N」等の定型パターン＋ヒューリスティックで
  章タイトルを検出し、PDFしおり（アウトライン）またはMarkdown見出しに変換
- **段落自動整形**: OCRの改行ノイズをルールベースで段落に結合する
  （LLM/外部APIは使わずオフラインで完結させること）。日本語は無空白結合、
  英語は半角スペース結合、英単語のハイフン分割は結合してハイフン除去

### OCRエンジン

NDLOCR-Lite（外部リポジトリ）をサブプロセスとして呼び出す。GPU不要。
`is_available()` で導入状況を確認し、未導入時は「画像PDF」以外の形式選択時に
明確な警告を表示する。前処理・後処理（置換辞書）はOCR結果を受け取った
アプリ側で行い、NDLOCR-Lite自体の改造はしない。

## 非機能要件

- **外部ネットワーク通信を行わない**（OCR初回セットアップ時のgit clone除く）
- 個人の学習目的での利用を想定した注意書きをREADMEに含める
- キャプチャ中はマウス・キーボード操作が干渉する旨を明記する
- 設定ファイル（config.json）は個人環境依存のためバージョン管理対象外とする
