## 重要な発見

### 1. CONF 値と実際の精度の乖離

XML の `CONF`（信頼度）値は、004.png の本文では 0.998〜1.000 と非常に高い値を示しています。しかし、実際には「GPT-4」が「〓PT-4」、「LLM」が「lm」など、明らかな誤認識が含まれています。これは、ndlocr_cli が誤った認識結果に対しても高い信頼度を出力する傾向があることを示唆しています。

### 2. 誤認識のパターン

- **英数字頭文字**: G→〓、I→（欠落）、L→l など
- **記号**: ■→K、(→〓、®/™→〓 など
- **漢字の部品類似**: 商→育、題→乃、夫→ヲ、存→右 など
- **異体字・旧字体**: 年→年、理→理 など（過去の調査でも確認）
- **語尾・助詞**: つ→っ、に→4 など

### 3. ページごとの特徴

- **表紙（002.png）**: 大きな文字・英語・デザイン要素が多く、最も誤認識が多い
- **注意書き（003.png）**: 日本語本文主体で比較的安定だが、記号・一部漢字で誤認識
- **本文（004.png）**: 日本語本文主体で最も安定だが、英語略語・記号で誤認識
