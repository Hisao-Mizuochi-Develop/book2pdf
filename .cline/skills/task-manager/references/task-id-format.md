# task-id-format

## タスクNo体系

- 形式: `### 001###-### 短縮名`
- 実際の例: `OT001001-scaffold`

## 構成要素

| 要素 | 桁数 | 説明 |
|---|---|---|
| ユースケースNo | 3桁 | 機能の大分類 |
| 通番 | 3桁 | ユースケース内の連番 |
| 短縮名 | 任意 | 内容を表す英数字・ハイフン |

## 記録形式

### tasks.md

```markdown
| タスクNo | タスク名 | 担当 | 開始日 | 完了日 | ステータス | タスク詳細 |
|---|---|---|---|---|---|---|
| OT001001 | プロジェクト雛形作成 | - | 2026/01/01 | 2026/01/01 | 完了 | ... |
```

### work_log.md

```markdown
## OT001001 プロジェクト雛形作成

### 実施予定
- 日時: ...
- 目的: ...
- 前提条件: ...
- 実施予定のコマンド: ...

### 実施実績
- ...
```
