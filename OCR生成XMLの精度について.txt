実施内容の確認

backend/app/services/pdf_generator.py の _insert_text_line() で、XML の Y 座標を PDF 座標系（左下原点）に正しく変換
XML の Y は上端からの距離、PDF の insert_text の point は baseline（下端）を基準に配置されるため、以下の変換式を採用
pdf_y = pdf_height - (xml_y * scale_y) - font_size
XML の上端を PDF の上端位置に合わせ、フォントサイズ分下げて baseline 位置を決定
